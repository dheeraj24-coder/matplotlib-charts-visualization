

# 📊 Matplotlib Charts Visualization

A simple Python project that demonstrates how to create multiple charts using **Matplotlib**. This project displays four different chart types in a **2×2 subplot layout** with customized colors, titles, labels, and figure styling.

---

## 🚀 Features

* 📈 Line Chart
* 📊 Bar Chart
* 🥧 Pie Chart
* 🔵 Scatter Plot
* 🎨 Custom Figure & Axes Background Colors
* 📏 2×2 Subplot Layout
* 🐍 Beginner-Friendly Python Code

---

## 🛠️ Technologies Used

* Python 3.x
* Matplotlib
* NumPy

---

## 📂 Project Structure

```
Matplotlib-Charts/

├── charts.py          # Main Python file
├── requirements.txt   # Project dependencies
├── README.md          # Project documentation
└── images/
    └── output.png     # Screenshot of generated charts
```

---


Install the required library:

```bash
pip install matplotlib numpy
```

---

## ▶️ Run the Project

```bash
python charts.py
```

---

## 📸 Output

The program generates a dashboard containing:

* 📈 Line Chart
* 📊 Bar Chart
* 🥧 Pie Chart
* 🔵 Scatter Plot

All charts are displayed together in a **2×2 subplot layout**.
